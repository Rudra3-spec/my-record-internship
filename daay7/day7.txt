Ahh, understood bro!

But even if you run terraform apply inside terraform-gcp/, Terraform will read only the .tf files directly inside terraform-gcp/.

It will not automatically read vm/main.tf, vpc/main.tf or gke/main.tf.

To use those subfolders from the root, you need to call them as Terraform modules in the root main.tf.

That's why modules are relevant to your proposed structure.

====================================================================================================================================================================================================================================================================================

1. What are Terraform modules?
A module is a collection of Terraform configuration files used to create a particular infrastructure component.

In simple words, it is reusable Terraform code.

2. Example
Suppose you frequently create VMs with the same configuration.

Instead of writing the VM configuration again and again, you create one VM module and reuse it whenever needed.

terraform-project/
├── main.tf
└── modules/
    └── vm/
        └── main.tf
Your root main.tf can call that module:

module "my_vm" {
  source = "./modules/vm"
}
This tells Terraform to use the VM instructions inside that module.
