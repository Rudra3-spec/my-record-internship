ADC = Application Default Credentials.

In simple words, ADC is a set of Google authentication credentials that allows applications like Terraform to access your Google Cloud account.
Why do we need ADC?
Imagine:
- You have a Google Cloud account.
- Terraform wants to create a VM in your GCP project.
- But how will Google know that Terraform is authorised to create that VM?
ADC provides the authentication credentials.
How did we configure it?
We ran:
gcloud auth application-default login


This:
1. Opened Google login.
2. You signed in with your Google account.
3. Google generated authentication credentials.
4. Terraform can use those credentials to communicate with GCP.
Simple difference
Command	Purpose
gcloud auth login	Authenticates you for using gcloud CLI.
gcloud auth application-default login	Creates credentials for applications like Terraform

VPC = Virtual Private Cloud.

In simple words, a VPC is your own private virtual network inside Google Cloud.

It allows your cloud resources, like VMs and GKE clusters, to communicate with each other.
Example
Imagine you have created:
- VM Instance
