sudo systemctl cat mongod

This command shows the configuration used by the MongoDB systemd service.

It means it shows the instructions Linux follows to run MongoDB.

Think of it like a recipe that tells Linux:

Who should run MongoDB? → User=mongodb

Which program should be executed? → /usr/bin/mongod

Which configuration file should MongoDB use? → /etc/mongod.conf

What command should start it? → Defined in ExecStart.

For example:

[Service]
User=mongodb
ExecStart=/usr/bin/mongod --config /etc/mongod.conf
When Linux starts MongoDB, it reads these instructions and executes the specified command.

In simple words:

systemctl cat mongod = Shows Linux how MongoDB is configured to start and run.

sudo cat /etc/mongod.conf = Shows MongoDB's own settings, like port, database location and log location.
